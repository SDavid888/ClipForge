# ClipForge

Klipelő és vágó játékosoknak – Windowsra, teljesen a saját gépeden fut.

- **Azonnali visszajátszás:** Alt+F8 elmenti az utolsó 15 mp – 5 percet (játék, Discord és mikrofon külön sávon, a Spotify soha nem kerül bele).
- **Vágó:** vágás, hangerők kiegyenlítése, zene alá, exportálás (YouTube, Discord 10 MB alatt).
- **Magyar felirat** a saját videókártyádon, a barátok hangjuk alapján felismerve, mindenki saját színnel.
- **Jelölők és automatikus vágás:** nevetés, reakciók, Rocket League-gólok, robbanások.
- **Könyvtár, montázs, magyar felület.**

## Telepítés

1. Töltsd le a legújabb **`ClipForge-Setup.exe`**-t a [Releases](../../releases/latest) oldalról.
2. Indítsd el. Ha a Windows azt írja, hogy „A Windows megvédte a számítógépet”: **További információ → Futtatás mindenképp** (a program nincs digitálisan aláírva).
3. Az első feliratkészítéskor a program letölti a magyar beszédfelismerőt (kb. 2,9 GB, csak egyszer).

A ClipForge magától jelez, ha új verzió van (Beállítások → Frissítések).

Rendszer: Windows 10/11, 64 bit. Felvételhez NVIDIA, AMD vagy Intel videókártya ajánlott (processzorral is megy, csak lassabban).

A mellékelt programok és modellek licencei a telepítés mappájában, a `licenses` alatt találhatók.
